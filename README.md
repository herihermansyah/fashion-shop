## 🚀 Tech Stack

Proyek ini dibangun menggunakan teknologi web modern:
* **Framework:** Next.js 16 (App Router) & React 19
* **Compiler:** React Compiler Enabled (Optimasi otomatis)
* **Styling:** Tailwind CSS v4, CVA (`class-variance-authority`), & `tailwind-merge`
* **State Management:** Zustand (Ringan & Cepat)
* **Slider/Carousel:** Swiper.js
* **Language:** TypeScript

## 🛠️ Instalasi

1. **Clone Repositori**
```bash
   git clone [https://github.com/herihermansyah/fashion-shop.git](https://github.com/herihermansyah/fashion-shop.git)
   cd fashion-shop
Instal Dependensi
Gunakan pnpm untuk memasang seluruh package yang dibutuhkan:

Bash
   pnpm install
Jalankan Server Lokal (Development)

Bash
   pnpm dev
Buka http://localhost:3000 di browser kamu untuk melihat hasilnya.

Build untuk Produksi

Bash
   pnpm build
   pnpm start
